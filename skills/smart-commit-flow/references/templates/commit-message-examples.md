# Commit Message Examples

## 功能
- `feat(search): 新增條件篩選與歷史紀錄`
- `feat(ui): 新增首頁空狀態提示`

## 修 bug
- `fix(auth): 修正 refresh token 失敗時的重試策略`
- `fix(ui): 修正深色模式下文字對比不足`

## 重構 / 效能
- `refactor(data): 移除重複 mapping 並統一轉換入口`
- `perf(list): 降低重繪次數以改善滑動卡頓`

## 建置 / CI
- `build(gradle): 調整版本鎖定策略以避免依賴漂移`
- `ci: 新增 PR 檢查工作流並上傳測試報告`
