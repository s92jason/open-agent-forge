# 評分報告格式範本

> 評分報告必須嚴格遵循以下格式。每個區段的內容依據題目 prompt 中的評分標準填寫。

---

## 格式規範

```
# <題目名稱> — 評分報告

ーーーーーーーーーーーーーーーーーーーー

## 👍 做得好的地方

- <正面評語 1>
  - 證據：`<檔名:行號>`
- <正面評語 2>
  - 證據：`<檔名:行號>`
- ...

ーーーーーーーーーーーーーーーーーーーー

## 😕 可以改進的地方

- <改進建議 1>
  - 現狀：`<檔名:行號>` 的做法
  - 建議：改進方向與理由
- <改進建議 2>
  - 現狀：`<檔名:行號>` 的做法
  - 建議：改進方向與理由
- ...

ーーーーーーーーーーーーーーーーーーーー

## 👎 違反事項

- ❌ <違反描述 1>
  - 證據：`<檔名:行號>`
  - 扣分：-<N> 分（原因）
- ❌ <違反描述 2>
  - 證據：`<檔名:行號>`
  - 扣分：-<N> 分（原因）
- ...

（若無違反事項，寫「無」）

ーーーーーーーーーーーーーーーーーーーー

## 分數：<N>/100

### 計算說明
- 基礎分：100 分
- <扣分項目 1>：-<N> 分
- <扣分項目 2>：-<N> 分
- ...
- **最終分數：<N>/100**
```

---

## 撰寫原則

1. **三段式結構**：👍（優點）→ 😕（改進空間）→ 👎（違反事項），順序不可調換
2. **全形破折號分隔線**：使用 `ーーーーーーーーーーーーーーーーーーーー` 分隔各區段
3. **違反事項必須附證據**：每個 ❌ 項目都要有 `<檔名:行號>`，不可籠統帶過
4. **分數在末尾**：`分數：<N>/100` 放在報告最後，附上計算說明
5. **客觀具體**：避免模糊用語（如「還不錯」「有待加強」），改用具體描述
6. **嚴格遵循題目 prompt**：評分標準以 prompt 為準，不自行發明標準
